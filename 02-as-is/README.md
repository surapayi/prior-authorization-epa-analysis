# As-Is: Manual Prior Authorization for an Outpatient MRI

This folder shows how prior authorization (PA) works today, what goes wrong, and what the baseline looks like in numbers.

## Read in this order

1. **[As-is swimlane](as-is-swimlane.png):** who does what, from order created (T0) to response received (T2).
2. **[Pain points](pain-points.md):** where the process loses time and staff effort.
3. **[Baseline KPIs](as-is-baseline.md):** reference values for each KPI, with sources.

## How the swimlane was built

The flow comes from public sources and general knowledge. It has not been checked by clinic staff or clinicians. The appeal step is shown as a dashed box because it is out of scope, but it is kept to show real practice.

## About the numbers

The baseline values are reference estimates from published sources, not measurements from a real clinic. Where I could not find a reliable source, the table says "no data" instead of filling a gap. KPI definitions are in the [scope statement](../01-scope/scope-statement.md).
