# As-Is Baseline KPIs

Reference values for the manual PA process. These are published estimates, not measurements from a real clinic. KPI definitions and formulas are in the [scope statement](../01-scope/scope-statement.md).

| KPI | Washington-based (main) | National (cross-check) | Notes |
|---|---|---|---|
| Turnaround time (T0 to T2) | No data | No data | 1 |
| Clinic staff effort per PA | About 26 min | About 26 min | 2 |
| Cost per PA (clinic side) | $29.01/hr × 26 min = **$12.57** | $22.08/hr × 26 min = **$9.57** | 3, 4 |

CAQH cross-check for cost: $15.12 per manual PA for specialists (CAQH Index 2023). Washington has no separate figure.

## Notes

1. **Turnaround.** I found no published figure for the full time from order created to response received. The CMS rule sets 7 calendar days for standard decisions for covered payers, but that is a deadline for the payer's decision only. It is not a baseline for T2 − T0, so I show it for context only.
2. **Staff minutes.** The 26 minutes is the average that specialists reported for a manual PA in the 2023 CAQH Index (2022 data). It is a self-reported total per transaction. CAQH does not say which steps it includes, so it may not match this project's "active staff time" definition. I use it as a single rough value. The minutes are national, so only the wage differs between the two columns.
3. **Wages.** BLS OEWS median for medical secretaries and administrative assistants: Seattle-Tacoma-Bellevue about $60,350 per year, US about $45,930 per year, each divided by 2,080 hours. Wages exclude benefits. [Confirm both figures on bls.gov.]
4. **CAQH cost.** CAQH reports provider-side cost per manual transaction using its own method. It will not match minutes × wage exactly. The gap is expected, since CAQH is likely to include costs beyond base wages.
